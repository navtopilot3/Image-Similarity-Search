# Image Similarity Search (Поиск похожих товаров) 

Система визуального поиска товаров на основе метрического обучения (Metric Learning). Проект позволяет загрузить фотографию товара и мгновенно найти визуально похожие позиции в базе данных (на основе датасета Shopee Product Matching).

В основе решения лежит архитектура **DINOv2** (Vision Transformer) и функция потерь **ArcFace**. Для быстрого векторного поиска используется индекс **FAISS**.

### Данные (Изображения товаров)
В качестве основы проекта используется датасет **Shopee - Product Matching** с платформы Kaggle. 
* **Откуда скачать:** Вы можете загрузить датасет со страницы соревнования [Kaggle Shopee Product Matching](https://kaggle.com).
* **Что нужно скачать:** Нам нужен архив `train_images.zip`, содержащий тренировочные фотографии товаров.

## Структура проекта

Проект разделен на две логические части: исследовательскую (Jupyter / Python скрипты) и продуктовую (веб-приложение).

### Исследовательская часть (Обучение)
* `1_eda.py` — Разведочный анализ данных (EDA): поиск полных дубликатов, конфликтующих меток, вычисление среднего цвета датасета и анализ геометрии изображений.
* `2_baseline.py` — Базовое решение на основе ResNet50 + ArcFace с поддержкой распределенного обучения (DDP).
* `3_tests.py` —  Эксперименты: сравнение backbone-моделей (ResNet, EfficientNet, DINOv2, Swin), типов пулинга, функций потерь (SubCenter ArcFace), подбор гиперпараметров через Optuna и тестирование ансамблей.
* `4_inference.py` — Финальное обучение модели DINOv2 на полных данных, создание FAISS-индекса и сохранение артефактов (`inference_model.pth`, `inference_index.faiss`, `inference_database.csv`).
* `5_modelcheck.py` — Анализ качества полученного пространства эмбеддингов: проверка на сдвиг (Embedding Drift), тестирование на OOD-данных (изображения вне домена - Places365), анализ Hubness и построение UMAP/t-SNE проекций.

### Веб-приложение
* `app_fastapi.py` — Backend на FastAPI. Принимает изображение, прогоняет через модель DINOv2 и возвращает топ-K похожих товаров из базы FAISS.
* `app_streamlit.py` — Frontend интерфейс на Streamlit для взаимодействия с API.

## Установка и запуск

**Подготовка данных и моделей**

Для работы приложения в папке `data/train_images/` должны находиться изображения товаров, а также следующие артефакты, сгенерированные скриптом `4_inference.py`:

*   `inference_model.pth` — веса обученной модели DINOv2.
*   `inference_index.faiss` — построенный векторный индекс.
*   `inference_database.csv` — база метаданных с путями к картинкам.

### Вариант 1: Запуск через Docker

** Запуск контейнеров**
Откройте терминал в корне проекта и выполните команду:
```bash
docker-compose up --build
```
** Проверка работы**
* Веб-интерфейс (Streamlit) будет доступен по адресу: `http://localhost:8501`
* Документация API (Swagger FastAPI): `http://localhost:8000/docs`

---

### Вариант 2: Локальный запуск

**Подготовка окружения**
Убедитесь, что у вас установлен Python 3.9+. Клонируйте репозиторий и установите зависимости:
```bash
git clone https://github.com
cd Image-Similarity-Search
pip install -r requirements.txt
```

**Запуск бэкенда (FastAPI)**
Сервер подниметься на порту 8000:
```bash
uvicorn app_fastapi:app --host 0.0.0.0 --port 8000
```

**Запуск фронтенда (Streamlit)**
В новом окне терминала запустите пользовательский интерфейс:
```bash
streamlit run app_streamlit.py
```

### Особенности решения

*   **Селективность:** Использование порога косинусного сходства (0.5) позволяет модели эффективно отсеивать случайные изображения (OOD) и мусорные запросы с AUROC = 0.98.
*   **Изотропность пространства:** Разные классы товаров ортогональны друг другу, а эффект "супер-хабов" полностью подавлен (медиана появлений в топ-5 равна 4.0).
*   **Архитектура:** Использование предобученных мощных трансформеров (DINOv2) с частичной разморозкой слоёв позволило достичь высоких метрик Recall/mAP без полного переобучения тяжелой сети.
